PROJET : CalculIMC
Langage : Kotlin
Modele : Empty Views Activity
SDK minimal : API 24

OUVERTURE DU PROJET
1. Ouvrir Android Studio.
2. File > Open... puis selectionner le dossier CalculIMC.
3. Attendre la synchronisation Gradle.
4. Lancer l'application sur un emulateur (API 24 ou superieur).

FORMULE : IMC = poids / (taille x taille)

FICHIERS PRINCIPAUX
- app/src/main/java/com/example/calculimc/MainActivity.kt
- app/src/main/res/layout/activity_main.xml
- app/src/main/res/values/strings.xml
- app/src/main/res/values/colors.xml

DEPOT GITHUB (a completer par l'etudiant)
1. Creer un depot sur GitHub (ex. CalculIMC).
2. Dans le dossier du projet :
     git init
     git add .
     git commit -m "TP Calcul IMC"
     git branch -M main
     git remote add origin https://github.com/<utilisateur>/CalculIMC.git
     git push -u origin main
